# Test CIF files

Real crystal structures for the X-ray structure tests (`tests/test_crystal.py`), from the
[Crystallography Open Database](https://www.crystallography.net/cod/) (COD), whose data
are in the public domain. Each file is unchanged, named after its compound and COD number:

| File | Compound | Why it is here |
|---|---|---|
| `naphthalene_cod_2311090.cif` | naphthalene, 80 K | the molecule sits on an inversion centre: half of it in the file |
| `hydroxybenzaldehyde_cod_2217204.cif` | 4-hydroxybenzaldehyde | a whole molecule in a general position |
| `ferrocene_cod_7033930.cif` | ferrocene | a metal on an inversion centre, rings disordered over two parts |
